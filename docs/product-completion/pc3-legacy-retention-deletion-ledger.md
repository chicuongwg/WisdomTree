## Proven-dead deletion ledger

No code met the **PROVEN DEAD** standard in PC3. In particular, an internal zero-consumer result did not qualify an authenticated legacy route for deletion because external callers and retention behavior have not been retired.

## Deliberately preserved data

- All migrations, immutable Note/Material versions, provenance support rows, audit events, historical translations/proposals, and release manifests/snapshots remain untouched.
- No schema/table/route was deleted solely because a legacy screen is absent.
